## 5. 白盒测试任务定义

**目标**：读源码，找出真实缺陷（逻辑错误、边界、竞态、资源泄漏、安全），逐条给出可复现证据。**只记录不修复**（修复归下一个代理）。

**重点区域（按风险排序）**：
1. `src/git.js`：`readSource`/`readSourceFromDisk` 路径校验（遍历、符号链接逃逸、realpath 竞态）、`assertInside` 边界（`relative` 返回 `''`/`..`）、超时与输出上限
2. `public/features/config-dim.js`：表达式求值优先级/结合性、三值传播、`\` 续行（偶/奇反斜杠）、块注释内指令、区间 `from/to` 差一错误、分支栈（嵌套 #if、#elif 链、#else）
3. `src/kconfig/parser.js` + `evaluate.js`：`source` 递归（环、缺文件）、`$(VAR)` 替换、choice 语义、select/imply 传播、不动点不收敛（迭代上限）、`.config`/autoconf.h 转义（字符串含引号/反斜杠）
4. `web-src/editor.js`：`refineC` 预处理状态机（无名 #define、行内 `#`、字符串/注释内 `#`、连续 `#` 行、`#include <…>` 尾部）、`textInputGuard`（组字窗口 350ms、直通键映射、`expectLiteralNext`）
5. `public/features/tree.js`（含未提交改动）：`beforeinput` 映射派发（同一键双触发？ASCII 半角是否可能走到 beforeinput？）、过滤框 Ctrl+j/k/Tab 与既有 ↑/↓/Esc 状态交叠、`renderTree` 焦点恢复
6. `src/lsp.js`：`lspReferences` 合并去重键、`openDocuments` LRU 200 与 `syncedHashes` 一致性、`resetLspSession` 与在飞请求竞态、prewarm 与 didOpen 竞态
7. `src/compile-db.js` 指纹：换 arch/autoconf 后旧索引分片复用是否误用（context-hash 不匹配场景）、原子写失败残留 tmp
8. `src/symbol-search.js`：`searchSymbolReferences` 分桶排序稳定性、正则转义、autoconf.h 读取上限
9. `public/features/*.js` + `keyboard-nav.js`/`vim-nav.js`：捕获/冒泡双层 keydown 的双触发或漏键（quickpick 与全局组合键）、`matchAction` Shift 变体边界（数字键/非数字键）
10. 安全横切：所有路由 `src/policies/request.js` 校验覆盖（新 `/kconfig/values` 等）、响应中用户可控内容是否全部 `textContent`（XSS）、`git grep -e <词>` 参数注入面（word 词法限制）、CSP/iframe sandbox
11. 资源与健壮性：超时清理（timers/Pending map）、`stores`/缓存 TTL、大文件/大输出路径、并发 resolve 的 `resolving` Map

**方法要求**：
- 先通读上述文件，形成缺陷假设；每个假设用**最小复现**证实后才计入报告：
  - 纯逻辑：`node -e` / 临时脚本直接 import 模块（ESM，注意 `import()`）
  - API 层：curl 本机 8766（POST/GET 按 routes 模式）——只读或幂等操作；**禁止触发 resolve/checkout/fetch/写盘类**
  - 前端：IAB 浏览器 + 页面内合成事件（见 §6）
- 每条问题：`编号 | 严重级(安全/高/中/低) | 文件:行 | 现象与根因 | 复现证据(命令/输出) | 建议修法(一句话)`
- 复现不了的“感觉有问题”一律标「存疑」或不写；宁缺勿滥
- 可为验证写临时脚本（放 `/tmp` 或 `scripts/whitebox-*.mjs` 并在报告注明用途，不要混入产品路径）

## 6. 浏览器与 IME 模拟工具箱

IAB 每次 JS 调用都要先 bootstrap（每个调用都是全新内核）：

```js
const browserPluginRoot = process.env.ZCODE_PLUGIN_ROOT ?? process.env.CLAUDE_PLUGIN_ROOT;
const { join } = await import("node:path");
const { pathToFileURL } = await import("node:url");
const { setupBrowserRuntime } = await import(
  pathToFileURL(join(browserPluginRoot, "scripts", "browser-client.mjs")).href
);
await setupBrowserRuntime({ globals: globalThis });
const browser = await agent.browsers.get("iab");
```

- 新 tab：`browser.tabs.new()` → `goto("http://127.0.0.1:8766/")` → `waitForLoadState({state:"domcontentloaded"})` + 等 3s（页面会恢复上次仓库/文件）
- 观察 UI：`tab.playwright.evaluate(() => ...)` 读 DOM（#quickpick.hidden、#current-file、document.activeElement、getComputedStyle 颜色等）；**本模型看不了截图**，视觉断言用 DOM/计算样式
- **真实 CUA 组合键在 IAB 会丢 key/code**：用页面内合成 `KeyboardEvent`（带正确 key/code，如 ctrl+alt+p 用 `code:'KeyP'`）
- **IME 形态模拟**（上轮黑盒漏检的教训，必测维度）：
  - `keydown` 带 `keyCode: 229`（fcitx 透传怪癖）
  - `beforeinput` `{inputType:'insertText', data:'、'}`（直通提交，在 #file-tree 上派发）
  - 全角字符（`＊` U+FF0A 等）
- 现有回归基线：`npm run check`、`npm run e2e`、`CHROME_BIN=/usr/bin/google-chrome npm run test:keyboard`（当前 20/20）
