打开代码仓库

读取本地仓库，或克隆一个远程 Git 仓库。

单击选中（不进入）；双击或 Enter 进入并回填路径；选中后按字母跳转，↑/↓ 选择。

也可输入仓库内的子目录；应用不会修改源码或分支。

支持 HTTPS、SSH、scp 风格和 file://；私有仓库使用系统 Git 凭据。

LLM 设置

选择厂商和模型，API Key 仅保存到系统密钥环（macOS 钥匙串 / Linux Secret Service）。

按已保存 Key 从 OpenAI 获取文本模型；返回可见不代表当前项目一定有调用额度。

仅「自定义兼容服务」可选；阿里云百炼等 Anthropic 兼容网关选 Anthropic Messages。

保存前会用该 Key 请求模型服务验证连通性；保存后无法从页面读回，留空则保留系统密钥环中已有 Key。

检测到环境变量配置，环境变量优先于本页面保存的选择。

文档知识库

解释代码时优先检索这些目录；命中后不再联网。当前仓库的 Documentation/docs/doc 会自动纳入。

编辑器环境

关联本地 vim/neovim 与插件环境；未检测到或选择「内置」时，代码窗口使用 code-reader 自带编辑器。

配置名对应 ~/.config/<配置名>；留空使用默认 ~/.config/nvim。插件数来自 lazy.nvim / pack / vim-plug 目录统计。

全键盘导航

两侧栏被输入法抢占时可用 Ctrl+Alt+Shift+B / Ctrl+Alt+Shift+I。Ctrl+Alt+B/Ctrl+Alt+I 是「去代码树/去解释窗口」：面板已开但焦点在代码区时按一下把焦点送进去，焦点已在面板内时再按才收起。任意窗口（含对话框、提交详情、解释栏、代码树、引用列表）都支持完整 Vim 导航：j/k 在可操作项之间移动或逐行滚动，可带计数（5j）；Ctrl+d/Ctrl+u 半屏、Ctrl+f/Ctrl+b/PageDown/PageUp 整屏，阅读区还可用 Space/Shift+Space；gg/G 首个/最后一个目标（12gg/12G 跳到第 12 个），H/M/L 首/中/末（阅读区为顶部/中部/底部），0/^/$ 首/末项（阅读区横向滚到最左/最右），o 激活当前项（Enter 走浏览器原生）；/ 在当前窗口内搜索，Enter 定位、n/N 下一个/上一个、Esc 清除高亮。解释栏里先 Tab 或点击链接进入项列表模式，Esc 退回阅读模式；文件树里 / 直接跳到过滤框。任意窗口按 Ctrl+Alt+K 出现字母标签（代码区按行打标签，输入标签即跳到该行；其它元素输入标签即点击/聚焦）；按 Ctrl+Alt+F 输入两个字符，匹配处出现标签，输入标签即跳转。标签层自动限定在当前顶层窗口，不会点到遮罩后面的元素；打开侧栏/对话框后焦点自动跟进；历史菜单/文件树右键菜单支持 ↑/↓ + Enter，Esc 返回；分隔条聚焦后 ←/→ 调整宽度。

浏览器限制

浏览器保留快捷键无法被网页接管：Ctrl-W（关闭标签）、Ctrl-T（新标签）、Ctrl-N、Ctrl-R（刷新）、Ctrl-P（打印）、F5、Alt-←/→。另 :! shell 与 :w 写盘不可用，编辑改动只保存在内存。
